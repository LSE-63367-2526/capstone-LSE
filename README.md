# Codebooks for MY498 Capstone

This repository includes all codebooks, Markdown files, and supporting materials used to collect data through the YouTube Data API v3 and analyse the collected data using cosine similarity with word embeddings generated by IndoBERTweet and Multilingual-E5-base, as well as TF-IDF. It also contains the materials used to classify collected comments using fine-tuned IndoBERTweet models for toxicity and polarisation, trained on the IndoDiscourse dataset.

Details of the markdown files and codebooks in this repo are as follows: 

- "getcomments.rmd" - This R Markdown file is used to collect all comments from all the videos in YouTube Indonesia's playlist for the first to fifth series of the Indonesian Presidential Debate 2024.

- "getanalysis_dataset.rmd" - This R Markdown file filters out videos with fewer than 10 comments, generating the dataset used for all analyses in this study.

- "buzzerdetection_behavioural.rmd" - This R Markdown file contains code used to detect buzzer-like accounts based on behavioural analysis.

- "buzzerdetection_content.ipynb" - This .ipynb file contains code used to detect buzzer-like accounts based on content analysis, using cosine similarity with word embeddings generated by IndoBERTweet and Multilingual-E5-base, as well as TF-IDF.

- "indobertweet-polar-full-kaggle-final.ipynb" - This .ipynb file contains the code used to fine-tune the IndoBERTweet model for binary classification of polarising comments using the IndoDiscourse dataset, distinguishing between polarising and non-polarising comments.

- "indobertweet-toxic-full-kaggle-final.ipynb" - This .ipynb file contains the code used to fine-tune the IndoBERTweet model for binary classification of toxic comments using the IndoDiscourse dataset, distinguishing between toxic and non-toxic comments.

- "indobertweet_inference_full.ipynb" - This .ipynb file contains the code used to apply the fine-tuned models generated in "indobertweet-polar-full-kaggle-final.ipynb" and "indobertweet-toxic-full-kaggle-final.ipynb" to the collected comments. The code performs threshold tuning and classifies comments as polarising and/or toxic. 

- "videos_stats.pdf" = This .pdf file contains the video-level statistics of each YouTube video from which comments were collected. 

Note: In line with LSE's ethical guidelines and YouTube's data access and privacy considerations, the full dataset is not shared or published in this repository. However, users with approved access to the YouTube Data API can use the getcomments.rmd script to collect the comments, after which the remaining codebooks can be used to reproduce the subsequent analysis.
